# scripts/

Repository tooling: `check_repo_hygiene.py` (no data, images, checkpoints or secrets in git; notebook output rules).

`fetch_model.sh` (`make fetch-model`): downloads the model package from the GitHub Release `model-v1.0.0` with `curl` (no token), checks `manifest.json` against a pinned sha256 and every file against the manifest; resumable and idempotent; `--check` only verifies a folder. Folder: the `DEST_DIR` argument, else `MODEL_HOST_DIR` resolved as Compose does (environment, then `.env`, relative to the repository root), else `artifacts/model_package/final-P1a-kg-onnx`. The package is CC BY-NC 4.0, non-commercial.

`smoke_test.py` (P1-BSH-04, standard library only): the post-deploy check. Waits for `/ready` (default 120 s; a failed model load stops at once), then checks `/health`, one `/predict` with a synthetic PNG generated in the script (response fields and consistency, not the prediction) and `/metrics` (the `milk10k_` metrics, model ready, the `/predict` counted). `python3 scripts/smoke_test.py [--base-url URL]` (default `API_BASE_URL` or `http://127.0.0.1:8000`); exit 0 pass, 1 fail, 2 usage error.

`mlflow_import.py` (`make mlflow-import`, `make mlflow-ui`): imports the finished training run history in `training/results/` (read-only) into a local MLflow store, `artifacts/mlflow/mlflow.db` (SQLite, gitignored), with its own venv in `artifacts/mlflow/.venv` from the pinned `requirements-mlflow.txt` (MLflow 3.18.0). One experiment `milk10k-run-history`: one run per row of `experiments_scores.csv`, the fold runs of `training_history.csv` nested under their seed runs with the epochs as step metrics, and the final run with `configs/final.yaml`, `final_metrics.json` and the runtime environment (paths excluded). Registered model `milk10k` version 1 = release 1.0.0: its source is the GitHub Release URL and its tags carry the manifest sha256 from `fetch_model.sh`; no files are copied. Idempotent: an import key on every run, and a second import adds nothing (it fails if an input file changed). The mapping is `mlflow_history.py` (standard library only, tested without MLflow in `tests/test_mlflow_history.py`). `make mlflow-import MLFLOW_ARGS=--check` prints the counts and a path scan of the store (counts only). Telemetry is off (`MLFLOW_DISABLE_TELEMETRY`, `DO_NOT_TRACK`); the UI binds to `127.0.0.1` only and runs until Ctrl-C.
